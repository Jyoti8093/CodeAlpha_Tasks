# CodeAlpha Internship Tasks

This repository contains my completed projects developed as part of my CodeAlpha Internship.

The repository includes two web development projects built using HTML, CSS, and JavaScript. Each project is organized in its own folder with its respective source files and documentation.

---

## Projects

### Task 1 - Image Gallery

A responsive and interactive image gallery website designed to showcase images in different categories.

#### Main Features

- Responsive gallery layout
- Nature, Animals, and Cities categories
- Category-based image filtering
- Interactive lightbox
- Previous and next image navigation
- Keyboard navigation
- Mobile-friendly navigation
- Smooth scrolling
- Responsive design

#### Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

Project folder: [CodeAlpha_ImageGallery](./CodeAlpha_ImageGallery)

---

### Task 2 - Calculator

A responsive calculator application developed using HTML, CSS, and JavaScript.

The project separates the styling and JavaScript functionality into dedicated folders to maintain a clean and organized project structure.

#### Main Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Percentage operation
- Decimal calculations
- Clear functionality
- Backspace/delete functionality
- Positive/negative number functionality
- Keyboard input support
- Responsive interface

#### Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

Project folder: [CodeAlpha_Calculator](./CodeAlpha_Calculator)

## How to Run

### Image Gallery

1. Open the `CodeAlpha_ImageGallery` folder.
2. Make sure the required images are inside the `image` folder.
3. Open `index.html` in a web browser.

### Calculator

1. Open the `CodeAlpha_Calculator` folder.
2. Keep the `css` and `js` folders in their respective locations.
3. Open `index.html` in a web browser.

For development, the projects can also be opened using Visual Studio Code with the Live Server extension.
