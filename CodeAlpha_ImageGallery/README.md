# CodeAlpha Task 1 - Image Gallery

## Project Overview

This project is a responsive and interactive Image Gallery developed as part of my CodeAlpha Internship.

The gallery allows users to browse images organized into different categories and interact with them through filtering and a full-screen lightbox interface.

---

## Objective

The objective of this project is to create a visually appealing and responsive image gallery using HTML, CSS, and JavaScript.

The project focuses on:

- Organizing images into categories
- Providing category-based filtering
- Creating an interactive image viewing experience
- Implementing responsive design
- Adding smooth user interactions

---

## Technologies Used

- HTML5 - Structure of the website
- CSS3 - Styling, layout, animations, and responsiveness
- JavaScript - Gallery interactions and functionality
- Font Awesome - Icons
- Google Fonts - Typography

---

## Features

### Responsive Design

The gallery is designed to work across different screen sizes, including desktop and mobile devices.

### Image Categories

Images are organized into three main categories:

- Nature
- Animals
- Cities

### Category Filtering

Users can filter the gallery to display images belonging to a particular category.

Available filters include:

- All Images
- Nature
- Animals
- Cities

### Interactive Lightbox

Clicking an image opens it in a larger lightbox view.

### Previous and Next Navigation

Users can move between gallery images using the previous and next controls.

### Keyboard Navigation

The gallery supports keyboard controls for navigation.

- Left Arrow - Previous image
- Right Arrow - Next image
- Escape - Close lightbox

### Mobile Navigation

The website includes a responsive navigation menu for smaller screens.

### Smooth Scrolling

Navigation and gallery interactions use smooth scrolling for a better user experience.

## How to Run

### Method 1 - Browser

1. Download or clone this repository.
2. Open the `CodeAlpha_ImageGallery` folder.
3. Make sure the images are placed inside the `image` folder.
4. Open `index.html` in a web browser.

### Method 2 - Visual Studio Code

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Open `index.html`.
4. Click "Go Live".
5. The gallery will open in your browser.
